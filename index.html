01 / LISORA QMS PRIVAT PROJEKT

Quality, organized.

Ett system. Tydligare arbetsflöden.

Ett kvalitetsledningssystem jag byggt för att samla dokumentstyrning, revisioner, CAPA, utbildning och riskhantering. Byggt med fokus på struktur, spårbarhet och användbarhet.

Next.jsTypeScriptPrismaSQLite
Utforska de tekniska valen+

Utmaningen var att göra sammanhängande kvalitetsflöden begripliga: dokument behöver versioner, revisioner leder till observationer och åtgärder måste kunna följas upp. Jag delade därför upp ansvaret i tydliga moduler.

Det här är ett eget utvecklingsprojekt, inte ett produktionssystem eller ett certifierat QMS.

03 / BOSTADSKOLLEN ÖPPEN KÄLLKOD

En backend för bostadsannonser med REST-endpoints och en utvecklingsmiljö med flera tjänster. Spring Boot hanterar applikationen, PostgreSQL lagrar data och Docker håller ihop miljön.
